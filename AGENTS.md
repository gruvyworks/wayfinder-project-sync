# wayfinder-project-sync — agent instructions

## Documentation

- Follow `docs/changes/README.md` for this repository's documentation layout
  and lifecycle rules.
- Follow any repository-specific exceptions defined there.
- Keep lifecycle documents for one change together in its active directory.
- Put approved PRDs in `docs/product/`, guides in `docs/guides/`, factual
  reference in `docs/reference/`, ADRs in `docs/decisions/`, and behavioral
  specifications in repository-root `openspec/`.
- Create documentation directories only when populated.
